# مناوب

نظام توزيع جداول الخفارات والعمل الإضافي لأقسام الصيدلة في المستشفيات.

## ما يفعله

- يولّد جداول الشهر الثلاثة تلقائياً في ثوانٍ: خفارات نهاية الأسبوع والعطل، خفارات أيام الأسبوع، والعمل الإضافي.
- يوزّع بعدالة حسب الساعات، مع حد أقصى 32 ساعة خفارة للموظف شهرياً وأيام راحة بين الخفارات.
- يراعي الإجازات السنوية والمرضية والطارئة والاعتذار عن الإضافي.
- عند المرضي أو الطارئ: يسحب الموظف ويعيّن بديلاً تلقائياً (الاحتياط أولاً في الإضافي)، ويعوّض المريض بخفارة أخرى في نفس الشهر.
- تثبيت الموظفين حسب رغبتهم في صيدلية معينة أو وقت معين أو الاثنين.

## الملفات

- `index.html`: نسخة عرض للمراجعة ببيانات تجريبية وأسماء وهمية. تعمل في المتصفح مباشرة، وتعديلات الزائر تبقى على جهازه فقط.

## الخطوة القادمة

الموقع الرسمي: تسجيل دخول، حفظ مشترك للبيانات، حساب منفصل لكل مستشفى، واشتراك شهري.
